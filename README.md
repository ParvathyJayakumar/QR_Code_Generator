# QR_Code_Generator
A simple and customizable QR Code Generator built using Python. This tool allows you to create QR codes for text, URLs, or any other data and save them as image files. It's a quick and efficient way to encode information in a scannable format.

**Features**

->Generate QR codes for any text or URL.

->Save the QR codes as image files (e.g., PNG).

->Customize the QR code size, colors, and error correction level.

->Batch QR code generation (optional feature).

->Easy to use and extend for other functionalities.


**Tech Stack**

Programming Language: Python

Libraries Used:

              qrcode: For generating QR codes.

              pillow: For image processing and customization.
